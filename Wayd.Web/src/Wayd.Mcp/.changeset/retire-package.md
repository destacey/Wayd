This is the last release of `@wayd/mcp`: the package is retired and receives no further updates. The Wayd API serves MCP itself at `/mcp` on its address, with every tool here under the same name and many more; sign in, or send your personal access token in the `x-api-key` header. The server now says so in its instructions, in the first tool result of a session, and on stderr, naming the address on the API it is configured for. See [Moving from @wayd/mcp](https://wayd.dev/docs/getting-started/mcp-server#moving-from-waydmcp).
