# Navigation

Wayd's interface is organized into several key areas accessible from the sidebar navigation.

## Sidebar Navigation

The left sidebar provides access to all major areas of the application:

- **Home** - Active planning intervals, your projects, the risks assigned to you, and your teams' sprints
- **Organizations** - Teams, employees, and the functional org chart
- **Planning** - Planning intervals and roadmaps, plus Planning Poker and Story Maps when those features are enabled
- **Work Management** - Workspaces and sprints
- **Product Management** - Products, releases, versions, release packages, deployments, delivery metrics, rollout, and environments (shown when the feature is enabled)
- **PPM** - The projects dashboard, portfolios, programs, projects, strategic initiatives, and strategic themes
- **Settings** - Application configuration and administration

A section or item you have no permission to view is left out of the menu. The button at the left of the header collapses the sidebar to icons; on a small screen the sidebar opens as a menu from that button instead.

## Header

The top header provides:

- **Search** - Global search (Ctrl+K) across Wayd and documentation
- **Documentation** - Opens the in-app documentation
- **Profile** - Click your avatar for **Account** (your [profile](./your-profile.mdx)), **Theme**, **API Specification**, and **Sign Out**

## Global Search

Press **Ctrl+K** (or **Cmd+K** on Mac) to open the global search modal. Search results are grouped by category and scoped by your permissions.

### Searchable Entities

| Area | Searchable Items |
| --- | --- |
| **Work** | Work items, workspaces |
| **Organizations** | Teams, teams of teams, employees |
| **Planning** | Planning intervals, PI iterations, sprints, PI teams, PI objectives, roadmaps |
| **PPM** | Projects, programs, portfolios, strategic initiatives |

### Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| **Ctrl+K** / **Cmd+K** | Open search (App scope) |
| **Ctrl+D** | Switch to Docs scope (when open) |
| **Ctrl+K** | Switch back to App scope (when open) |
| **↑ / ↓** | Navigate results |
| **Enter** | Open selected result |
| **Esc** | Close search |

## Breadcrumbs

Breadcrumb navigation appears below the header, showing your current location and allowing quick navigation to parent pages.
