# Technology Stack

## Backend (.NET)

| Technology | Purpose |
|-----------|---------|
| .NET 10.0 | Runtime and SDK |
| ASP.NET Core | Web API framework |
| Entity Framework Core | ORM and database access |
| SQL Server | Database |
| Wolverine | CQRS command/query dispatch and in-process events |
| FluentValidation | Input validation |
| Mapster | Object mapping (DTOs) |
| NodaTime | Date/time handling |
| CSharpFunctionalExtensions | Result pattern |
| Hangfire | Background job processing |
| Serilog | Structured logging |
| Microsoft.AspNetCore.OpenApi | OpenAPI document |
| NSwag | TypeScript and C# client generation |
| Scalar | API reference |
| Microsoft.FeatureManagement | Feature flags |
| ASP.NET Core Identity | User management |
| OIDC identity providers / local JWT | Authentication |
| OpenTelemetry | Observability |
| ModelContextProtocol.AspNetCore | Hosted MCP endpoint (`/mcp`) |
| NCalc | Scoring model formulas |
| CsvHelper | CSV imports |
| Microsoft Graph SDK | Microsoft Entra ID people sync |

## Frontend (Next.js)

| Technology | Purpose |
|-----------|---------|
| Next.js 16 | React framework (App Router) |
| React 19 | UI library |
| TypeScript 7 | Type safety |
| Ant Design 6 | UI component library |
| Redux Toolkit | State management |
| TanStack Table | Data grids (via the `WaydGrid` house component) |
| oidc-client-ts | OIDC authentication (PKCE redirect flow) |
| react-markdown | Markdown rendering |
| dayjs | Date formatting |
| @dnd-kit | Drag and drop |
| SignalR | Real-time communication |
| Serwist | PWA service worker tooling |
| Ant Design Charts | Charts |
| React Flow (`@xyflow/react`) | Dependency maps and workflow diagrams |
| Mermaid | Diagrams in the in-app docs |

## MCP Server (`@wayd/mcp`)

| Technology | Purpose |
|-----------|---------|
