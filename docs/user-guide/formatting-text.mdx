# Formatting long text

Descriptions, business cases, notes and every other long-text field can be edited in a **document editor**: bold, lists, links, tables and code look the way they will once saved, as you type. The document editor is behind the **WYSIWYG Markdown Editor** feature flag (`wysiwyg-markdown-editor`); an administrator turns it on in **Settings → Feature Flags**. With the flag off, those fields keep the markdown text box.

Whichever editor you use, Wayd stores the text as markdown. Detail pages, the API and the MCP tools read it the same way, so nothing about existing records changes when the flag is turned on.

## The toolbar

| Button | What it does | Shortcut |
|---|---|---|
| Text style | Normal text, or heading 1, 2 or 3 | Type `#`, `##` or `###` and a space at the start of a line |
| Bold, Italic, Underline, Strikethrough | Format the selection | Ctrl+B, Ctrl+I, Ctrl+U, Ctrl+Shift+S |
| Inline code | Format the selection as code | Ctrl+E, or wrap text in backticks |
| Link | Add, change or remove a link | |
| Bulleted, Numbered and Task list | Turn lines into a list | Type `-`, `1.` or `[ ]` and a space |
| Quote | Indent as a quotation | Type `>` and a space |
| Code block | A block of code | Type three backticks, optionally a language such as `sql`, then a space |
| Table | Insert a table, then add or delete rows and columns | |
| Horizontal rule | A dividing line | Type `---` |
| Undo, Redo | Step back or forward through your edits | Ctrl+Z, Ctrl+Shift+Z |

On a Mac, use ⌘ in place of Ctrl.

A link must be a web address (`https://…`), an email link (`mailto:…`) or a path in Wayd (`/…`). Typing `wayd.dev` adds `https://` for you; other kinds of address are refused.

Pasting from Word, Outlook, a web page or Azure DevOps keeps headings, bold, italic, lists, links and tables, and drops fonts, colors and spacing. Images are kept only when they come from a web address; an image pasted from a file on your computer is left out.

The count under the editor is the length of the stored markdown, which is a little longer than the text you see. Once it reaches the field's limit, the editor stops accepting additions.

## Text you never edit is never rewritten

Opening a record's edit form and saving it without changing the text keeps the text exactly as it was, even where the editor would write it differently, such as `*` bullets it writes as `-`. Undoing every change you made has the same effect. Only an edit makes the editor write the field again, and the [activity log](./activity-log.mdx) records a change only then.

## Formatting the editor cannot keep

A few kinds of markdown display on detail pages but have no equivalent in the document editor: footnotes, collapsible sections, keyboard keys, HTML comments and blocks, and special characters written as HTML entities (`&nbsp;`). When a field holds any of them, a warning above the editor names what it found. Editing that field removes them; to keep them, close the form without saving.
